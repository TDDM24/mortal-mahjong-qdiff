# 用白くん的口径重测我的数据：收获与发现

日期：2026-11-27
样本：55 场（有报告 + 有段位pt）
方法：完全按白くん！的口径（Q差 ≥ 0.25 记为悪手），用我们自己的 JS 流水线复算，
分类维度用 review JSON 里自带的标记（`entry.shanten`、`entry.at_self_riichi`、`entry.at_self_chi_pon`）与 `snap.riichi`。

## 一、先回答「为什么是 0.75」

**没有依据，是整数。** 0.25 / 0.50 / 0.75 / 1.00 正好是 250 点一档的整数值
（若 Mortal 的 Q 以 1000 点为 1 单位，即 250/500/750/1000 点）。

我做了一次阈值扫描（0.10→1.50，步长 0.05），看每个阈值下的「超阈值决策占比」与段位pt 的相关：

| 阈值 | 平均占比 | r | p |
|---|---|---|---|
| ≥0.25 | 13.0% | −0.252 | 0.063 |
| ≥0.50 | 7.2% | −0.226 | 0.098 |
| ≥0.75 | 4.3% | −0.350 | 0.008 |
| **≥1.00** | **1.8%** | **−0.449** | **<0.001** |
| ≥1.25 | 0.4% | −0.341 | 0.011 |
| ≥1.50 | 0.05% | −0.025 | 0.858 |

**结论**：

1. 曲线**平滑上升**，在 0.75 处**没有拐点**——所以 0.75 不是数据校准出来的，是人为取整
2. 预测力在 **1.0 附近达到峰值**，不是 0.75
3. 三个等级的差别本质是**同一分布的三个分位点**（13% / 7.2% / 4.3% / 1.8%），
   不是三种「性质不同」的错误
4. 阈值太低（0.25）会被大量无关紧要的微差稀释；阈值太高（1.5）事件太少，噪声主导

## 四、四条收获

**① 2向聴 的悪手是最强的单一指标**

0.25 阈值下 r=−0.30（p=0.026），0.75 阈值下 r=−0.39（p=0.003）——**都比「全部」更强**。

解释：2向聴是「选择空间最大」的阶段。聴牌时能打的牌很少（5.77% 悪手率），1向聴次之，
3向聴+ 还没成型；只有 2向聴 时手牌有多种走向，决策质量差异才会被放大。

**② 被立直時的悪手与结果无关（−0.017）**

这和他把「被立直時」单列为一个重点指标的做法**相反**。
在本样本里，防守阶段的失误并不预测单场结果——和前面「防守 r=−0.32，弱于严重失误」一致。

**③ 仕掛け時的悪手率最高（24.5%），但与结果无关（−0.157）**

鸣牌后的选择明显更容易出错（是平均的 1.9 倍），但对结果没有可测影响。
可能因为鸣牌局本身方差大、样本少（每场 4.7 手）。

**④ 1向聴的悪手跟结果正相关（+0.124）**

方向反了，且不显著。猜测是「保守」的代理：1向聴时选择保守（少进张、重安全）会提高 Q 差却降低放铳风险。

## 五、为什么这条线索值得追

如果把「严重失误」从单一指标改成**按向聴分层**，会得到：

- 聴牌/1向聴：几乎不预测 → 可以不作为训练重点
- **2向聴：最强预测** → 训练重点应放在「两向聴的牌效率/进张选择」
- 3向聴+：弱预测

这比「减少恶手」具体得多，也比「盯牌效总均值」有方向。

## 六、必须说明的局限

1. **多重比较**：9 类 × 2 阈值 = 18 个检验，Bonferroni 阈值 0.05/18 ≈ 0.0028。
   2向聴（0.003）**刚好压线**，属于「值得追」但不是「已确认」
2. n=55 场，2向聴每场约 49 手，场间波动大
3. 分类依赖 mjai-reviewer 的 `shanten` 字段（摸牌前的向听），与白くん的面板口径可能有细微差异
4. 阈值扫描的峰值（1.0）本身也是从同一批数据选出来的，**有选择性偏差**；
   要确认必须在新的数据上复验
