- **触发条件与后果**：Mac 壳在 127.0.0.1:48623（占用顺延）起 HTTP 服务且无 token。浏览器任意恶意网页可发 **simple request**（`Content-Type: text/plain`，无 CORS 预检）POST 一段 JSON——服务器不查 Content-Type 照样解析——用户 Mac 上弹出 NSSavePanel，文件名由攻击者控制（社工诱导）；用户误点「存储」攻击者内容落盘。缓解：必须用户亲手确认保存框、绑定 127.0.0.1（main.swift:65 ✓）、响应无 ACAO 头跨域读不到 ✓、/report 只接 16 位 hex 无 SSRF（main.swift:201 ✓）、静态文件有路径穿越防护（main.swift:188-189 ✓）——故定 P2 不定 P1。Python 桌面版**无此攻击面**（全代码库无内嵌 HTTP 服务，grep 仅命中出站请求）。
- **修法**（任一）：
  ```swift
  // A：校验 Origin——浏览器跨域 simple request 必带 Origin
  if let origin = headers["origin"], !origin.isEmpty { respond(..., status: "403 Forbidden"); return }
  // B：启动时生成随机 token 经 WKUserScript 注入 JS，/save 与 /report 校验 X-MJ-Token
  ```
- **验证方法**：`curl -X POST http://127.0.0.1:48623/save -H 'Content-Type: text/plain' --data '{"name":"x.txt","mime":"text/plain","base64":"aGk="}'`（App 运行时）——现状弹保存框，修复后应 403。

### P2-8　研究：聚类回归的 p 值用正态近似而非 t(G−1)，显著性被系统性高估 —— 维度①统计正确性

- **定位**：`analysis.py:79` —— `p = [erfc(abs(v) / sqrt(2)) for v in t]`（cluster_ols 内）
- **证据**（实跑，t 分布用不完全贝塔函数手算，df=G−1）：M2 严重失误 p_z=0.0007（报告写「<0.001」）vs p_t(19)=0.0031；M3 严重失误 0.0030→0.0087；M4 0.0018→0.0061；M6 放铳率 0.0003→0.0018。G≈17–20 时 p 约被压低 3 倍。
- **触发条件与后果**：聚类数 ~20 时正态近似反保守；当前所有结论在 t 口径下仍 <0.01 无翻转，但 M2/M5 的「<0.001」严格说应为 0.003 量级。

- **验证方法**：与 statsmodels `cov_type='cluster'` 对照，或手算 betai(df/2, 1/2, df/(df+t²))。
