## 三、研究侧数字变化（n 50 → 48）

剔除 2 行「指标口径 = 旧算法」（报告已 404，指标不是本口径算的）后：

| 指标 | 旧 | 新 |
|---|---|---|
| 严重失误 | r=−0.40, p=0.004 | **r=−0.38, p=0.008** |
| 压力分数 | −0.36, p=0.010 | **−0.34, p=0.018** |
| 合计失分 | −0.27, p=0.060 | **−0.24, p=0.096** |
| 每100次牌效决策 | +0.02, p=0.875 | **−0.02, p=0.919** |
| 每100次防守决策 | −0.19, p=0.194 | **−0.11, p=0.465** |
| M4 牌效 | +1.90 (SE 3.25) | **+1.06 (SE 2.39)** |

## 四、Windows 侧要做的事

```bat
git pull
cd mahjong\desktop
build_win.bat
```

会重新打出 `dist\麻将记录\麻将记录.exe`。这次 Windows 侧源码（`mr.py`、`core.py`、`store.py`、
`ui/review.py`）都已改好，**不需要再手改**。

重打包后建议顺手验三件事：

1. 打开「数据」页 → 导出 Excel → 看「每100次防守决策」列不再是整列空（P0-3）。
2. 粘同一个牌谱链接两次 → 第二次应提示「已经记过」，而不是多一行（P1-4）。
3. 打开内嵌复盘页 → 链接应自动粘进输入框，且不会来回跳（P1-5）。
