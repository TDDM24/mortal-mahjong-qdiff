# 工具横评方案：同类复盘工具能给我什么、缺什么

**目的**：不是评「谁更好」，而是回答一个具体问题——
**用我已有的 10 场数据，这些工具各自能产出什么？哪些是我的软件已经有的？哪些是我没有的？**

排除了 NAGA（付费商用，本项目不收费，定位不同，只作背景引用）。

## 3. 测量指标（7 项，全部有操作定义）

| # | 指标 | 操作定义 | 记录方式 |
|---|---|---|---|
| M1 | **覆盖度** | 10 场中成功分析几场 | 计数 |
| M2 | **粒度** | 能否看到逐手（而非只有整场汇总） | 0/1 |
| M3 | **可导出** | 能否得到数值（JSON/CSV/表格），而非截图 | 0/1/2（2=结构化） |
| M4 | **单场耗时** | 从上传到出结果的人工操作分钟数 | 计时 |
| M5 | **可重复性** | 同一场跑两次，关键数字是否一致 | 一致/不一致/无法测 |
| M6 | **指标个数** | 该工具给出几个可比较的指标 | 计数 |
| M7 | **段位换算** | 是否把指标换算成段位/雀力 | 有/无（有则记方法是否公开） |

补充记录（定性）：
- 是否给「恶手分类」？分类标准是否公开？
- 是否给置信区间/信度？
- 是否考虑对手强度、桌型、拔线？
- 是否支持纵向（多场汇总）？

## 4. 各工具的操作步骤

### 4.1 Mortal（基准）

1. 打开 <https://mjai.ekyu.moe/>，粘贴牌谱链接
2. 过验证码 → 生成报告
3. 记录：rating、各分类失分、恶手列表条数
4. 下载 JSON（本项目已有）

### 4.2 MAKA（需雀魂账号）

1. 雀魂客户端 → 牌谱 → 选一场 → 点工具栏的 MAKA 标记 → 分析
2. 记录：给出的评分项及数值、恶手条数、能否导出
3. 注意：每天 5 次，10 场要分两天跑；**记录当天剩余次数**

### 4.3 白くん！（Chrome 扩展）

1. Chrome 安装扩展
2. 打开 Mortal 报告页（同一场）
3. 记录：「雀力战斗力」「真恶手率」、恶手分类的条目数
4. 重点：它把雀力换算成**雀魂/天凤段位**——记下换算结果，与本项目算的段位pt 对照

### 4.4 BigCoach / Gokujan（需注册）

1. 注册账号（用一次性邮箱，避免后续骚扰）
2. 上传牌谱 → 分析
3. 记录：给出的指标名与数值、免费额度用完的提示
4. 若强制付费才能看关键数据，**记「付费墙」并跳过**

### 4.5 mortal conveniencer（Chrome 扩展）

1. 安装扩展
2. 打开 Mortal 报告页 → 扩展把结果写进 Google 表格
3. 记录：导出表格的列名（这是它能提供的最大价值：**批量导出**）

## 6. 分析计划

### 6.1 描述性

- 每个工具的 M1–M7 汇总（上表）
- 与 Mortal 的对比：**哪些指标是 Mortal 已有数据的再包装**，哪些是**新的信号**

### 6.2 一致性（能拿到数值的工具才做）

对 10 场，比较各工具的「恶手/失误」指标与本项目 `严重失误` 的 **Spearman 秩相关**：

| 相关系数 | 解释 |
|---|---|
| ρ > 0.8 | 测的是同一件事，**无增量** |
| 0.5 < ρ ≤ 0.8 | 部分重叠，有增量 |
| ρ ≤ 0.5 | 测的是不同维度，**有独立价值** |

这一步回答核心问题：**「白くん！的真恶手率」和「我的严重失误」是不是同一把尺子？**

### 6.4 判定规则

- 若某个免费工具在 M1–M7 上**全面覆盖本项目**，则本项目的价值只剩「开源+可复现」，需在 README 里如实说明
- 若所有工具都缺「纵向统计 / 区间估计 / 混杂控制」，则本项目的定位成立

## 7. 限制

1. 10 场样本，只够描述，不足以下统计结论
2. 界面读数靠人工录入，有记录误差
3. 付费墙工具只能测到免费额度为止
4. 工具会更新，本方案记录的是**测试当日**的行为（记录日期与版本号）
5. 我（AI）无法登录任何账号，**本节必须由你本人执行**；执行完把 CSV 给我，我做 6.2 的一致性分析和 6.3 的矩阵填充
