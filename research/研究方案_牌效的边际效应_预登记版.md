# 研究方案：牌效指标的边际效应与升段相关性

**版本** 1.0（预登记版）
**日期** 2026-11-27
**性质** 观察性研究，预登记；判定规则在看数据之前写死

---

## 1. 研究问题

1. **组间**：Mortal 口径下的「牌效失分」与玩家段位是否相关？相关强度多大？
2. **非线性**：这种关系是否**前陡后平**（低水平区间每提升 1 分收益大，高水平区间趋于饱和）？
3. **独立性**：控制「严重失误」与对手强度后，牌效是否仍有独立效应？
4. **交互**：牌效的作用是否随水平（段位）变化？严重失误的作用是否也随水平变化？

**动机**：单人 62 场的探索性分析发现，在牌效 5.1–6.9 的窄区间内，牌效的场间波动与单场段位pt 无关（r=−0.07，95% CI [−0.32, +0.18]），而严重失误稳健相关（r=−0.48）。这可能是**区间限制**造成的假阴性（range restriction），也可能是真实的**边际效应递减**。本研究用跨水平样本区分这两种解释。

## 3. 假设与预测

| 编号 | 假设 | 预期结果 | 若成立的含义 |
|---|---|---|---|
| **H1** | 牌效失分与段位负相关 | r ≤ −0.50 | 牌效在跨水平上有效 |
| **H2** | 关系非线形，低段位区间斜率更陡 | 二次项系数 < 0 且显著；或最低段位区间斜率 ≥ 最高区间的 2 倍 | 存在边际效应递减 |
| **H3** | 控制严重失误后，牌效仍有独立效应 | 偏相关 ≤ −0.30 且 CI 不含 0 | 牌效不是严重失误的代理 |
| **H4** | 严重失误在所有区间都有效 | 各分层内 r ≤ −0.35，层间差异不显著 | 大错是通用货币 |
| **H5**（次要） | 防守指标在高段位更重要 | 高段位层防守 r 绝对值 > 低段位层 | 水平的瓶颈会转移 |

**H2 是核心**：它决定「练牌效」和「练少犯错」哪个在什么阶段更重要。

## 5. 抽样与样本量

### 5.1 分层定义

按**当前段位**分 4 层，每层要求「在该段位已打 ≥200 场」（排除刚升上来/刚掉下来的过渡期）：

| 层 | 雀魂 | 天凤 | 预期牌效（待验证） |
|---|---|---|---|
| L1 入门 | 雀士（银之间） | 一般卓（級位） | 8–15 |
| L2 中坚 | 雀傑（金之间） | 上級卓（1級） | 6–9 |
| L3 上位 | 雀豪（玉之间） | 特上卓（四段+） | 5–7 |
| L4 顶尖 | 雀聖・魂天（王座） | 鳳凰卓（七段+） | 4–6 |

> 层内目标：段位稳定、可核对（用 nodocchi / 牌谱屋 id 验证，**不接受自报**）。

### 5.2 每人场次

每人 **20 场**（连续最近，不许挑）。理由：单人数据显示 20 场的分半信度 r₂₀=0.89，足够。

### 5.3 样本量与功效

- **H1**（相关）：r=0.4、α=0.05（双侧）、power=0.8 → n=47。考虑测量误差衰减（≈0.87 倍），**目标 60 人**
- **H2**（非线性）：4 层 × 15 人，可检出层间斜率比 ≥2 的差异
- **H3**（偏相关）：在 n=60 下可检出 r=0.35 的独立效应

> 若第一阶段只能凑到 40 人（10/层），H1 仍可做（可检出 r=0.45），H2 降级为探索性。

### 5.4 招募的现实约束（必须写进方案）

每个牌谱要在 mjai.ekyu.moe **手动提交一次（过验证码）**，无法自动化。因此总量受志愿者的时间限制：

- 60 人 × 20 场 = 1200 次提交 ≈ 每人 20–30 分钟
- 折中方案：第一阶段 40 人 × 20 场（800 次），第二阶段只对 L1/L4（两端）追加到 30 场

## 6. 指标定义（口径必须一致）

所有指标由同一套代码计算（`mahjong-js/web/src/`，已与 Python 原版逐字段比对通过）：

| 指标 | 定义 | 方向 |
|---|---|---|
| 合计失分 | Σ(Q_期望 − Q_实际) × 100 / 决策数 | 越低越好 |
| **牌效失分** | 同上，限「牌效」类决策 | 越低越好 |
| 防守失分 | 同上，限「防守」类决策 | 越低越好 |
| **严重失误** | 每 100 手 Q 差 ≥1.0 的决策数 | 越低越好 |
| 每 100 次防守决策 | 防守失分 / 防守决策数 × 100 | 越低越好 |
| 压力分数 | 立直 + 隐形威胁合并，每 100 次切牌 | 越低越好 |
| 平台 | 天凤 / 雀魂 | 协变量 |
| 段位 | 有序（L1–L4 再细分为具体段位） | 因变量 |
| 平均单场段位pt | 20 场段位pt 变化之和 / 20 | 因变量 |
| 对手平均 R | 每场同桌三人的 R 均值，20 场再平均 | 协变量 |
| 桌型构成 | 一般/上级/特上/鳳凰 的场次占比 | 协变量 |
| 拔线局比例 | 对手出现「整局ツモ切り」的场次占比 | 协变量/敏感性 |

**注意**：`rating`（Mortal 给的评级）**不作为证据变量**——它由同一批 Q 差推导，与五项循环。

## 7. 数据采集

### 7.1 志愿者需提供

1. 平台 + 玩家 id（nodocchi / 牌谱屋可查）
2. 最近连续 20 场的**牌谱链接**（天凤 `log=` 后的 24 位 id；雀魂完整牌谱链接）
3. 对应 20 场的**报告 id**（在 mjai.ekyu.moe 提交后得到）
4. 同意条款勾选

> 牌谱与报告**必须成对**：牌谱给段位pt/对手R/拔线，报告给五项。只有牌谱没有报告 → 只能进因变量侧。

### 7.2 数据验证（自动化，三道）

1. **牌谱 ↔ 报告一致性**：报告的 `mjai_log` 与牌谱的牌局内容逐手比对（切牌序列、和了结果）
2. **顺位 ↔ 点变一致性**：牌谱 `sc` 字段的段位pt 与 nodocchi 记录比对（预实验 56/56 一致）
3. **段位真实性**：用玩家 id 在 nodocchi/牌谱屋查当前段位，与问卷填写比对，不符者剔除

### 7.3 排除标准（预先设定）

- 该段位场次 <200 场
- 20 场中友人/个室局 >0 场（`lobby != 0`）
- 20 场覆盖时间跨 >60 天（状态不稳定）
- 数据验证 1 或 2 不通过
- 报告缺失 >5 场

## 8. 统计分析计划

### 8.1 主分析

- **H1**：Spearman（段位序数 vs 牌效），报 r + 95% CI；同时报 Pearson 作敏感性
- **H2**：`段位序数 ~ 牌效 + 牌效²`，检验二次项；并画 LOESS 曲线 + 分层斜率
- **H3**：`段位序数 ~ 牌效 + 严重失误 + 对手R`（有序 logit 或线性近似），看牌效系数
- **H4**：按层分组的相关矩阵，比较层间是否同质（交互项）
- **H5**：同上，对防守指标

### 8.2 因变量的两种用法

| 用法 | 优点 | 缺点 |
|---|---|---|
| 段位（序数） | 长期稳定、无运气 | 分层粗糙 |
| 平均单场段位pt | 连续、精度高 | 含运气，20 场噪声大 |

**两个都报**，若结论不一致，以段位为主（更稳定），并说明分歧。

### 8.3 不确定性与敏感性

- Bootstrap（按人重抽 5000 次）给所有系数的 CI
- 敏感性 1：剔除有拔线局的场次
- 敏感性 2：只用 20 场中桌型一致的子集
- 敏感性 3：把「合计失分」替换「牌效」重跑（检验是否只是汇总口径的差异）
- 敏感性 4：只保留报告完整（20/20）的人

### 8.4 测量信度与衰减校正（预先设定）

每人的 20 场可以内部拆半（奇偶场），估计**每人**指标的拆半信度；再用 Spearman-Brown 校正到 20 场，得到组间比较时各指标的信度 `rel`。

- 报告 `rel(牌效)`、`rel(严重失误)`、`rel(合计失分)`
- 主分析同时报**未校正**与**衰减校正后**的相关系数：`r_true ≈ r_obs / √(rel_x × rel_y)`
- 若 `rel(牌效) < 0.6`，说明 20 场不足以稳定估计个人牌效，需在结论里注明，并把 H1 的判定降级为探索性

> 本方案第 5.3 节的「衰减 0.87 倍」是**假设值**，将由这次数据实测替代。

### 8.5 缺失数据

报告缺失 ≤5 场 → 用现有场次计算，但记录 n；缺失 >5 场 → 剔除。不做插补。

## 9. 判定规则（预先写死）

| 结论 | 判定条件 |
|---|---|
| **支持 H1** | Spearman r ≤ −0.40 且 95% CI 上限 ≤ −0.15 |
| **支持 H2（边际效应）** | 二次项 < 0 且 p<0.05；或 L1 层斜率绝对值 ≥ L4 层的 2 倍且两者 CI 不重叠 |
| **支持 H3（独立效应）** | 控制严重失误后，牌效偏相关 ≤ −0.25 且 CI 不含 0 |
| **支持 H4** | 各层严重失误的 r 均在 [−0.75,−0.30]，且层间交互 p>0.10 |
| **证伪 H2** | 二次项 ≥ 0，或各层斜率差异 <1.3 倍 → 无边际效应，线性关系 |
| **证伪 H1** | r > −0.20 且 CI 含 0 → 牌效与段位无关（在覆盖的区间内） |

**禁止事后改口径**：若主分析不显著，不得改用其他指标组合「找显著」；所有替代分析必须标注为探索性。

## 10. 伦理与数据管理

- 牌谱本身公开，但玩家 id 可关联身份：**只存 id + 报告 JSON**，不存姓名/联系方式

- 发表时只报分层汇总，不报个人
- 志愿者有权索取自己的分析结果（也是招募激励）

## 12. 局限（预先声明）

1. **自选择**：愿意交数据的人偏向认真复盘者，结论只能外推到这类人
2. **横断面**：只能证明相关，不能证明因果（「练牌效→升段」需要干预实验）
3. **20 场的测量误差**：会衰减相关系数，H1 的 r 是下限
4. **Mortal 尺子本身**：不同网络（4.1a/b/c）可能给出不同 Q，本研究固定 4.1b；尺子噪声未量化
5. **段位不等于水平**：平台机制、场次、运气都影响段位；用「200 场以上」部分缓解
6. **雀魂与天凤不可直接合并**：平台作为协变量，必要时分开报
