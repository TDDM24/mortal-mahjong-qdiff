## 1. 那个页面是什么

Mortal 的报告页（`mjai.ekyu.moe`）**叠加了「白くん！」Chrome 扩展**注入的统计面板。
证据：统计面板后面紧跟 `<img src="chrome-extensi…">`，且面板里的指标名（シン悪手率、大悪手率、
向聴別悪手率、被立直時悪手率）都是该扩展的功能。

Mortal 自己的部分只有一个 `rating`；其余都是扩展加的。

## 2. rating 的确切公式（源码级确认）

来自 [mjai-reviewer](https://github.com/Equim-chan/mjai-reviewer) `src/review/mortal.rs`：

```rust
if is_equal {
    raw_rating += 1.;
} else {
    raw_rating += (actual_q_value - min) / (max - min).max(1e-6);
}
...
let rating = (raw_rating / total_reviewed as f64).powi(2);
```

即：

$$
\text{rating}=\left(\frac1N\sum_{i=1}^{N}s_i\right)^2\times 100,\qquad
s_i=\begin{cases}1 & \text{选了 Mortal 的第一选择}\\ \dfrac{q_i^{实际}-q_i^{\min}}{q_i^{\max}-q_i^{\min}} & \text{否则}\end{cases}
$$

**两点关键**：

1. **min-max 归一化**：分母是该手候选的 Q 区间。候选都差不多时，一个 0.5 的绝对损失会被算成很小的扣分
2. **平方**：把平均分压缩，90 分以上需要平均 ≥0.949

→ **rating 测的是「你的选择在候选里排多高」，不是「你亏了多少 EV」。**

**复算验证**：对本地 55 份报告按此公式重算，与站点给出的 rating 相关系数 **r = 0.9976**（公式确认）。

## 3. 悪手率的口径反推

页面显示：`悪手率 12/153 = 7.84%`，`1向聴悪手 5/39`，`2向聴悪手 4/47`，`大悪手 5/58`，`シン悪手 9/105`。

从 HTML 里解析出 153 个决策中 **113 个**（其余 40 个是立直/鸣牌等非打牌动作，表格结构不同），
逐个还原候选 Q 值、实际选择、以及是否被标记：

| 观测 | 数值 |
|---|---|
| 被标记为悪手类的手数 | **12**（与页面 12/153 完全一致） |
| 被标记手的最小 Q 差 | **0.291** |
| 未被标记的失配手最大 Q 差 | **0.234** |
| 按 `Q差 ≥ 0.25` 计数 | **12 手** ← 精确命中 |

**结论：悪手 = 该手实际选择比 Mortal 最优低 0.25 以上。**
`1向聴悪手` / `2向聴悪手` 里的前缀是**当时的手牌向听数**（状态标签），不是更严的阈值——
1 向聴组的 Q 差 0.58–0.94、2 向聴组 0.29–0.86，区间完全重叠。

其余两个口径的推测（与检出数吻合）：

| 指标 | 页面值 | 复算 | 推测阈值 |
|---|---|---|---|
| 大悪手率 | 5/58 | Q差 ≥ 0.75 → **5 手** | 0.75 |
| シン悪手率 | 9/105 | Q差 ≥ 0.5 → **9 手** | 0.5 |

分母 153 / 105 / 58 不同，说明三者统计的**子集**不同（可能是「有意义的场面」「近听牌」之类），
具体子集定义无法从页面确定。**这一条只能标注为推测。**

## 4. 用 55 场检验：阈值越低，预测力越弱

因变量：单场天凤段位点变化。自变量：不同阈值下的「每场次数 / 总决策数」。

| 口径 | 每场次数 | 占决策 | r | 95% CI | p |
|---|---|---|---|---|---|
| Q差 ≥ 0.25（白くん 悪手） | 19.5 | 13.0% | −0.254 | [−0.49, +0.01] | 0.061 |
| Q差 ≥ 0.50 | 10.9 | 7.2% | −0.224 | [−0.46, +0.04] | 0.101 |
| Q差 ≥ 0.75（白くん 大悪手） | 6.6 | 4.3% | −0.349 | [−0.56, −0.09] | 0.009 |
| **Q差 ≥ 1.0（本项目 严重失误）** | 2.7 | 1.8% | **−0.448** | [−0.64, −0.21] | **0.001** |
| Mortal rating | — | — | **+0.156** | [−0.11, +0.40] | 0.256 |

**三条结论**：

1. **单调趋势**：阈值越高，与结果的关联越强。0.25 档不显著（p=0.061），1.0 档 p=0.001
2. **rating 与结果无关**（甚至符号为正）。原因就是 min-max 归一化把「量」的信息洗掉了
3. **白くん的 0.25 阈值落在我们证明无效的区间**：本研究显示 0.1–0.3 档失配与结果的相关是 +0.03

## 5. 与本项目的对比

| 维度 | Mortal rating | 白くん 悪手率 | 本项目 五项 |
|---|---|---|---|
| 公式 | 开源（已确认） | 闭源（本文反推 0.25） | 开源 |
| 测什么 | 选择在候选里的**相对位置** | 超阈值的**次数占比** | **绝对 EV 损失**（分类别） |
| 尺度 | 无量纲（min-max） | 次数/决策数 | 每 100 手 / 每 100 次该类决策 |
| 分类 | 无 | 按向听、按场况（被立直/兜牌/放铳/副露/立直） | 六类归因 + 向听 + 巡目 + 压力 |
| 跨场追踪 | 无（单场） | 扩展声称有（闭源、本地浏览器） | ✅ 有（自建数据集 + 统计） |
| 置信区间/信度 | 无 | 无 | ✅ 有 |
| 与结果的相关 | **0.16（不显著）** | 0.25 档 −0.25（不显著）；0.75 档 −0.35 | **−0.45（1.0 档）** |

## 6. 局限

2. 分母 153/105/58 的子集定义未确定
3. 预测力对比 n=55，各档 CI 互相重叠；**趋势是证据，单点差异不是**
